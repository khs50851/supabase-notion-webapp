# 견적서 웹 확인 서비스 MVP PRD

## 🎯 핵심 정보

**목적**: 노션(Notion)에 입력한 견적서 내용을 클라이언트가 별도 프로그램 설치 없이 웹에서 바로 확인하고, 필요 시 PDF로 다운로드할 수 있게 한다.
**사용자**: 노션으로 견적서를 작성해 클라이언트에게 전달하는 1인 프리랜서/소상공인(관리자)과, 공유 링크로 견적서를 확인하는 클라이언트

> 📌 이 문서는 MVP(v1) 요구사항에 1차 고도화(v2: 관리자 전용 레이아웃, 공유 링크 재발급, 다크모드)
> 결과를 반영한 최신 상태입니다. 개발 진행 이력은 `docs/ROADMAP.md`(현재)와
> `docs/roadmaps/ROADMAP_v1.md`(MVP 완료 이력 아카이브)를 참고하세요.

## 🚶 사용자 여정

```
1. [로그인 페이지]
   ↓ 로그인 성공

2. [대시보드(견적서 목록) 페이지]
   ↓ 노션 연동 여부 확인

   [미연동] → [노션 연동 설정 페이지] → 저장 성공 → [대시보드(견적서 목록) 페이지]
   [연동 완료] → 노션 DB의 견적서 목록 표시
   ↓

3. 관리자가 견적서 선택 후 공유 링크 생성/복사
   ↓ (카카오톡/이메일 등 외부 채널로 클라이언트에게 전달 — 서비스 범위 밖)

4. [견적서 상세 페이지] (클라이언트, 비로그인, 공유 링크로 접속)
   ↓ 견적서 항목·금액·발행일 확인
   ↓ PDF 다운로드 버튼 클릭

5. [PDF 파일 다운로드 완료]
```

## ⚡ 기능 명세

| ---------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ---------------------------- |
| **[F001]** | 노션 연동 설정        | Notion API 키와 견적서(invoice) 데이터베이스 ID를 입력해 견적서 데이터 소스를 연결 (항목 Items DB는 `항목` relation으로 자동 탐지) | 견적서 데이터를 가져오기 위한 필수 연결 고리                              | 노션 연동 설정 페이지        |

| **[F004]** | 공유 링크 생성·재발급 | 견적서별 고유 공개 링크를 생성하고 복사. 이미 발급된 링크는 재발급(회전)할 수 있으며, 재발급 시 이전 링크는 즉시 무효화됨          | 클라이언트에게 견적서를 전달할 접근 경로 확보, 유출된 링크 회수 수단 제공 | 대시보드(견적서 목록) 페이지 |
| **[F005]** | PDF 다운로드          | 견적서 상세 페이지에서 견적서를 PDF 파일로 다운로드                                                                                | 서비스의 핵심 가치(PDF 보관/전달)                                         | 견적서 상세 페이지           |

## ✅ 정합성 검증 결과

- 기능 명세(F001~F005, F010~F012)의 모든 기능 ID가 페이지별 상세 기능에 존재함
- 메뉴 구조의 모든 메뉴 항목(대시보드, 노션 연동 설정, 로그인, 회원가입, 다크모드 토글)이 페이지별 상세 기능에 존재함
- 견적서 상세 페이지는 메뉴가 아닌 공유 링크 전용 접근 경로이며, 메뉴 구조 문서에 "공개 접근" 섹션으로 명시함
- F011(다크모드)은 페이지 전용 기능이 아니라 전 페이지 공통 UI라 개별 메뉴 항목 대신 모든 페이지의 "구현 기능" 태그와 메뉴 구조의 "다크모드 토글" 줄에 반영함
- F012(관리자 전용 레이아웃)는 대시보드·노션 연동 설정 두 페이지에만 적용되며, 두 페이지의 "구현 기능" 태그에 모두 존재함
- 페이지별 상세 기능의 모든 구현 기능 ID가 기능 명세에 정의되어 있으며, 고아 기능/페이지 없음
